# Menu Matcher
**Menu Matcher** ist eine PWA App zum
- **Sammeln** von Ideen von Elementen für ein gemeinsames Date
- **Abstimmung** über die gesammelten Ideen durch beide Partner
- **Erstellung** eines gemeinsamen Menüs aus den Übereinstimmungen der Abstimmung 

## Installation

1. Gehe zu [https://bastl3r.github.io/menu-planner/menu_planner.html](https://bastl3r.github.io/menu-planner/menu_planner.html)
2. Öffne die Browsereinstellungen und Klicke **Installieren**
